# Oreflow: Готовый Мод Mindustry

Готовый ZIP в полном архиве проекта: `oreflow-mod-0.2.0.zip` рядом с этим файлом.
Импортировать в игре нужно именно этот ZIP, не полный архив исходников сайта.
Не распаковывай ZIP мода. Перезапусти клиент после импорта.

F7 открывает настройки на карте Серпуло. Выбери бур в игровом меню, затем
«Выбрать жилу» и кликни по руде. Подтверди предпросмотр. Автоматический
предпросмотр после первого построенного бура включается отдельным флажком.

По умолчанию купол выключен в игре: сначала подготовь его снабжение.
На сайте он включён для иллюстрации радиуса. Вода и энергия включены.
Все настройки можно изменить в F7. Выходы и питание подключаются снаружи.

Скрипты используют только ванильные блоки и очередь строительства. Мод
не добавляет контент и не обходит исследования, стоимость и правила сервера.
Проверка не сертифицирует все карты или модпаки. Начни с песочницы.

Лимит одной жилы: габарит 56 × 56 и до 1200 клеток. Слишком большой или
конфликтующий план отклоняется вместо частичного сноса базы.

Источник алгоритма: `shared/engine.ts`. Готовый общий код: `scripts/engine.js`.
Сборка из корня проекта: `node scripts/build-mod.mjs`.
Подробности и проверенные механики: `MECHANICS.md`.

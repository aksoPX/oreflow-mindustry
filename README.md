# Oreflow 0.2.0

Планировщик добычи для Mindustry на ПК и интерактивная веб-мастерская.

## Только Установить Мод

Готовый файл в полном архиве проекта: `mod/oreflow-mod-0.2.0.zip`.

1. Не распаковывай ZIP мода.
2. Mindustry: Модификации → Импортировать мод → выбрать ZIP.
3. Полностью перезапусти игру.
4. Открой карту Серпуло. Выбери бур в меню строительства.
5. F7 или кнопка Oreflow → Выбрать жилу → клик по руде.
6. Проверь предпросмотр, подтверди очередь и подключи внешние ресурсы.

Это нативный JavaScript-мод Mindustry, не JAR. Для установки не нужны Node,
Java JDK, Gradle и самостоятельная компиляция. Проверенные целевые релизы:
v146 и v160.8. На других сборках совместимость не заявлена.

## Возможности

- Несколько десятков плотных компоновок с соприкасающимися бурами.
- Резервирование реальных предметных и жидкостных портов.
- Настроенные мосты с проверкой дальности и одинакового типа концов.
- Гидронасосы на подходящем грунте, непосредственно рядом или через мосты.
- Расчёт воды с учётом типа бура, водоносности пола и ускорения насоса.
- Купол с настоящим радиусом; два внешних входа топлива.
- Титановые выходы 11/с либо пластановые с двумя загрузчиками по 20/с.
- Силовые узлы с лимитом 15 связей и проверкой изолирующих препятствий.
- Предпросмотр и обычные строительные планы, без бесплатных ресурсов.
- Автопредпросмотр после первого построенного бура, если включить в F7.

## Границы

Нет обещания абсолютного максимума или 100% покрытия. Для доступа к бурам
нужны служебные клетки. Неподключаемые буры исключаются; оставшаяся руда
показывается отдельно. Поиск не является точным решателем задачи упаковки.

Энергию нужно подать извне на узел, выходы подключить к ядру или хранилищам.
Куполу нужны 600 энергии/с и по 0,2 кремния и фазовой ткани в секунду.
Одиночная титановая лента после пластановой магистрали снизит её пропускную
способность. Не соединяй все выходы в одну перегруженную линию.

Существующие постройки не сносятся. Если целиком безопасный план не проходит
`Build.validPlace`, он отклоняется. В кампании нужны исследования и материалы.
Мультиплеер зависит от правил сервера. Сначала используй копию сохранения.

Отдельный «Конвейер-навигатор» от произвольной точки до ядра остаётся идеей.
В моде реализован только вывод внутри плана добычи.

## Структура Проекта

`src/` содержит сайт React/Vite, `mod/shared/engine.ts` содержит общее ядро,
`mod/scripts/` содержит готовые ES5-скрипты, `mod/mod.hjson` содержит метаданные.
`tests/` содержит браузерные тесты. `docs/MECHANICS.md` описывает механику.
`public/downloads/verification.json` содержит результаты проверок движками.

## Разработка

```sh
npm ci
npm run dev
```

```sh
node scripts/build-mod.mjs
npm run build
npx playwright test
node scripts/package-project.mjs
```

Сборка мода компилирует только общее TypeScript-ядро в ES5 и архивирует
нативную структуру Mindustry. Готовые скачанные ZIP устанавливаются без этого.

Тесты модификации: `python scripts/test-mod.py`. Они скачивают официальные
серверные JAR в локальный кэш и требуют Java 17. Никаких JAR игры в дистрибутив
проекта не включено.

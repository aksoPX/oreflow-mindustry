# Обязательный Промпт Для Изменений Oreflow

Исправляй сайт и нативный JavaScript-мод одним общим ядром
`mod/shared/engine.ts`. Сохраняй совместимость ES5/Rhino и не меняй отчёт
на PASS, пока проверки реально не пройдут на соответствующем артефакте.

Критическая регрессия: в строительной очереди юнита УЖЕ есть обычный BuildPlan.
Открой F7, выбери жилу, рассчитай предпросмотр и проверь добавление новых
планов без удаления, замены или пересечения старого плана. Повтори в v146
и v160.8. Отдельно проверь отсутствие игрока, null-юнита и пустую клетку.

`unit.plans` является полем Queue, не методом. Вызов `unit.plans()` запрещён.
Проверяй unit на null, перебирай Queue как коллекцию и используй её size
как поле. Не вызывай Java-поля как функции и не угадывай неизвестные API.
Существующая очередь должна остаться нетронутой после снятия снимка карты.

Используй только обычные BuildPlan ванильных блоков Серпуло. Не создавай
ресурсы, не завершай стройку мгновенно, не сноси постройки. Неполную
электросеть отклоняй. Воду, энергию, топливо купола и вывод к ядру
не объявляй бесплатными или автоматически доступными.

Сверь полный Result сайта и Rhino на одинаковом JSON-входе. Проверь ZIP
через zipfile.testzip(), mod.hjson в корне, идентичность двух ZIP мода и
наличие mod/oreflow-mod-0.2.0.zip внутри полного проекта. Явно перечисли
непроверенные сценарии и ограничения вместо обещания полного покрытия.
